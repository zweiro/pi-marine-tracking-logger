# PI MONIT - Marine Animal Tracking Web App

## Overview
This project is an academic project with the purpose to monitor sea turtle movements using satellite data. The app will fetch satellite data from an API, store it in a MongoDB database, and display it on a web app built with Vue.js. The app will also include features such as data visualization,
